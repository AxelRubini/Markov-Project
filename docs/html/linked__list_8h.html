void free_linked_list ( linked_list_t * list,
void(* free_func )(void *) )

Free a list and its nodes.

Each element stored in the list is freed using free_func if provided. This allows the caller to specify how to release the memory pointed by the data field of each node, avoiding both leaks and invalid frees.

Parameters
listList to free.
free_funcFunction used to free the stored data (may be NULL).
