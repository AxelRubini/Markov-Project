ssize_t recv_frame ( int fd,
char ** buf,
size_t * cap )

Receive a length-prefixed frame from a file descriptor.

The buffer pointed to by buf is resized as needed to hold the incoming data plus a null terminator.

Parameters
fdFile descriptor from which to read the frame.
bufAddress of a buffer pointer that will hold the frame data. The buffer is allocated or reallocated by the function.
capAddress of a variable containing the capacity of buf, updated when reallocation occurs.
Returns
Number of bytes read on success; 0 on EOF or empty frame; -1 on error.

int send_frame ( int fd,
const char * data_to_send,
size_t len )

Send a length-prefixed frame over a file descriptor.

The function first writes the length of the frame as a 32-bit value in network byte order, followed by the frame data itself.

Parameters
fdFile descriptor to which the frame is written.
data_to_sendPointer to the data buffer; may be NULL when len is 0.
lenNumber of bytes to send from data_to_send.
Returns
0 on success; -1 if writing fails or arguments are invalid.
