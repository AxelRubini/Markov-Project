Execute both tasks in multi-process mode.

Builds a frequency table from the input text and generates output text using that table.

Parameters
input_txtPath to UTF-8 input text file. NULL uses stdin.
output_csvDestination CSV file for the frequency table.
output_txtDestination file for generated text. NULL prints to stdout.
n_wordsNumber of words to generate.
wordStarting word for generation. NULL selects a random start.
Returns
0 on success, -1 on error.
